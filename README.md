# ProjectSignal

**Product Opportunity Intelligence for building-product sales teams.**

ProjectSignal turns fragmented construction activity into a ranked commercial pipeline by matching a customer's product portfolio to upcoming projects and adding modelled value, project stage, influence timing, stakeholders, and recommended next action.

## Demo stack
- Next.js App Router
- React + TypeScript
- Lucide icons
- CSS design tokens (no generic purple gradient, no Inter)
- Vercel-ready

## Run locally
```bash
npm install
npm run dev
```

## Validation disclaimer
The opportunity values in the current demo are model-derived examples for product validation. They are not published procurement values.
